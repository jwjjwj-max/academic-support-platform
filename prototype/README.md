# 学业帮扶智慧平台交互原型

这是依据《学业帮扶智慧平台 PRD v1.0》制作的零依赖浏览器原型，重点验证功能、角色权限、流程和状态，不代表最终视觉设计。

## 打开方式

直接双击 `index.html` 即可使用。为了获得稳定的文件导入和下载体验，也可以在本目录启动任意静态文件服务器。

例如：

```powershell
node server.cjs
```

然后访问 `http://127.0.0.1:4173/`。

也可以直接双击 `index.html`，无需启动服务器。

## 演示角色

- 学业攀登者：陈晨
- 学业领航者：林晓
- 管理员：学习部管理员

左侧顶部可以随时切换角色和期次。

## 推荐体验路径

1. 使用“学业攀登者”进入匹配中心，确认结对；
2. 在“我的帮扶”中上传帮扶照片并填写心得，切换另一学生角色确认材料；
3. 在“个人中心”查看本人参加过的往期帮扶记录；
4. 切换管理员审核报名并运行匹配，查看科目、专业、年级等匹配依据；
5. 在“成绩管理”分别导入上学期期末和本学期期末成绩单，提取绩点与专业排名；
6. 在“德育分名单”上传并发布名单文件，再切换学生角色下载文件；
7. 查看操作日志并刷新页面，检查关键操作和本地数据仍然存在。

## 本轮修改重点

- 学生报名不填写专业排名，帮扶科目改为手动输入；
- 匹配移除时间维度，提高专业权重并加入年级维度；
- 帮扶过程只保留照片和心得，取消帮扶计划与中期阶段；
- 学生端只展示本人前后两学期的全部课程绩点，不展示专业排名和公开榜单；
- 管理员分别导入两份成绩单，并从成绩单中提取绩点和排名；
- 德育分通过名单文件发布，取消证书和其他奖励；
- 个人资料增加年级、微信，并可查看本人参加过的往期帮扶。

## 真实边界

- 所有数据都保存在浏览器 `localStorage`，不会连接真实后端；
- 示例人员、成绩和指标均明确属于演示数据；
- 照片上传仅保存文件名、大小和说明，不保存或上传图片内容；
- 成绩单原型当前支持 CSV 导入；正式开发时可接入 XLSX 解析，并按学校实际表头配置字段映射；
- 德育分名单支持 CSV、XLS、XLSX、PDF，原型以 Data URL 保存在当前浏览器，单个文件上限 2 MB；
- CSV 导出、表单校验、状态变更、文件下载和本地持久化是真实可用的；
- 不发送短信、微信、邮件，也不接入教务系统和统一身份认证；
- “重置演示数据”会清除当前浏览器中本原型的操作记录。
